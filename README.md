## Project Description

The Task Management System is a web application designed to help a small startup manage and track daily tasks across a team.

The system provides a simple and organized way to create, view, update, delete, and filter tasks without relying on spreadsheets.

---

## Main Features

- Add new tasks
- Assign tasks to team members
- Set task priority
- Set task due dates
- View all tasks
- Sort tasks by due date
- Update task status
- Delete tasks
- Filter tasks by status
- Filter tasks by assignee
- Validate task information
- Responsive user interface

---

## Additional Features

The application also includes additional functionality to improve usability:

- Search tasks by title
- Display task count summaries
- Preserve task information after refreshing the page

---

## Task Information

Each task contains the following information:

- Task Title
- Assignee
- Priority
- Due Date
- Status

### Priority Levels

- Low
- Medium
- High

### Task Statuses

- To Do
- In Progress
- Done

---

## Project Requirements

The system is designed to satisfy the following requirements:

1. Users can add a task with a title, assignee, priority, and due date.
2. Users can view all available tasks.
3. Tasks are displayed according to their due dates.
4. Users can update the status of a task.
5. Users can delete tasks.
6. Users can filter tasks by status.
7. Users can filter tasks by assignee.
8. Task titles are required.
9. Due dates cannot be in the past.
10. The system contains at least five sample tasks when initially loaded.
11. The application supports different screen sizes.
12. Users can navigate between the All Tasks and Add Task views.
